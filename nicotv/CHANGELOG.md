# Changelog

## 2.16.3
- Swipe a chat message to the right to reply to it (sends a real Twitch reply).
- Locked channel emotes (sub / follower / bits) are shown greyed out with a lock; tapping explains what is needed.
- New "Sub" button with a QR code to the channel's subscribe page.

## 2.16.2
- Long-press a chat message to copy it.
- Triple-tap a chat message to open the moderation menu (mods only).

## 2.16.1
- Emote menu: always list the channel's emotes (sub / follower / bits).
- AFK screen is centered (only a tiny anti burn-in drift remains).

## 2.16.0
- Custom AFK message (Settings -> "AFK-Nachricht").
- Emote menu with Twitch, 7TV and BetterTTV tabs and search. The 7TV / BetterTTV tabs follow the corresponding settings.
- `/emotes` command and `E` shortcut.
- Added the `user:read:emotes` OAuth scope (re-login needed to see your own emotes).

## 2.15.0
- Original upstream version.
